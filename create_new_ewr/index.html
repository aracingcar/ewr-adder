EWR adder

Define a new environmental water requirement and watch it join the EWR tool's parameter sheet. The sheet below is a copy of the upstream parameter_sheet.csv; each rule you add is validated in your browser and appended as U_ rows, with a matching ewr_calc_config.json entry. You can also remove existing rows: use Delete in the preview table. Then either download the merged files to use with py_ewr yourself, or Submit to repository to propose the rule: that opens a pre-filled GitHub issue (you need a GitHub account), and a workflow re-checks it and opens a pull request for review. Nothing is sent anywhere until you press Submit on that issue. How this EWR works walks through what a rule asks for, as you type it or for any row of the sheet.

Definitions are remembered in this browser only. Download merged sheet and Download calc config give the two files py_ewr needs: pass them as the parameter_sheet and calc_config_path arguments of its evaluation functions. The CSV is written as Windows-1252, as py_ewr reads it. Submit to repository proposes the rules for inclusion upstream via an issue and an automatic pull request; very large submissions are copied to your clipboard to paste into the issue instead. Export / Import JSON saves and restores your definitions and pending deletions. Deleting every row of an EWR also removes its calc-config entries.
